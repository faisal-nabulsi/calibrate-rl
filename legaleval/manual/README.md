# `manual/` — paste worksheets for models with no API access

This folder is the working directory for the **manual-run workflow**
(`tools/manual_run.py`). Use it for a model under test that has no implemented
provider (no API), so its responses have to be captured by hand from a web UI.

Nothing here is pre-authored — the files below are **generated by the tool and
filled in by a human**. The folder is created automatically on first `export`,
so it's normal for it to hold only this README until you run a manual capture.

## What lands here

- `<model>_sheet.md` — a paste worksheet for one model: an incognito checklist,
  then each prompt under a `LEGALEVAL PROMPT <id>` marker with a blank
  `LEGALEVAL RESPONSE <id>` section to paste the model's raw reply into.

## Workflow

```bash
# 1. export a worksheet for one model (all prompts, or a subset)
python tools/manual_run.py export --model muse-spark
python tools/manual_run.py export --model muse-spark --prompts A1,B2

# 2. open manual/muse-spark_sheet.md and, per the incognito checklist,
#    paste each model reply under its RESPONSE marker (one fresh temp chat
#    per prompt; keep the first complete reply; no edits/regenerate).

# 3. ingest the filled-in sheet into a run dir (responses/<id>_<model>.json)
python tools/manual_run.py ingest manual/muse-spark_sheet.md
#    --run-id <id>  ingests into an existing run so manual + API models
#                   grade and score together.

# 4. grade and score exactly like an API run
python -m harness.grade runs/<run_id>
python -m harness.score runs/<run_id>
```

Manual responses are stamped `isolation: "manual-incognito"` (web UI, not a bare
API call) so the weaker isolation is auditable in every downstream artifact.

Known no-API models (see `tools/manual_run.py` `KNOWN_MODELS`): `gpt-5.5`,
`gemini-3.1-flash`, `qwen-3.7-plus`, `muse-spark`.
